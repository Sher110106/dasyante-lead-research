# Approved controls

- Access: public; no application login, explicitly selected by the user.
- Migration: copy current three live-test leads, evidence, Apollo profiles, review status and verified contact.
- Project: new `dasyante-lead-research`, active CLI team; do not modify other Vercel projects.
- Storage: dedicated private JSONBin collection; no destructive edits to unrelated records.
- Testing: isolated local fixtures; bounded hosted research/provider calls; no outreach.
- Secrets: ignored `.env` and server-only Vercel environment variables. Never place values in reports or browser code.
- Stop/ask: unavailable paid capacity, invalid credentials, destructive migrations, or a deployment-scope conflict.
